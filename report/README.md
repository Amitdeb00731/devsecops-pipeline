# Reports

The Phase 6 write-ups, produced once the pipeline is built and proven.

- `pipeline-security-report.md`: each gate, the weakness it was proven against, the
  failing and passing runs, and a gate-by-gate scorecard.
- `controls-mapping.md`: each gate mapped to NIST SSDF, OWASP SAMM and DSOMM, and
  the change-management, segregation-of-duties and audit-trail IT general controls.
- `business-report.md`: a business stakeholder report in corporate language, framed
  against UK operational resilience and SOX-style IT general controls.

See [docs/06-report.md](../docs/06-report.md).
